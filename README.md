## Sobre mim

Sou desenvolvedor Full Stack e Mobile formado em Sistemas para Internet pelo IFES. Trabalho no desenvolvimento de aplicações web e mobile unindo interface, lógica de negócio, integrações e organização de dados.

Tenho experiência com React, TypeScript, JavaScript, Flutter, Dart, Node.js, Firebase, Python e Django REST Framework, desenvolvendo desde protótipos visuais até aplicações com fluxo completo.

Atualmente venho evoluindo projetos como Nosso Voto, Portfólio Alexandre, Irrifes Tensiômetro e aplicações voltadas para gestão, colaboração e organização de dados. Meu foco é criar soluções claras, responsivas e úteis para pessoas reais.

## Organização dos meus projetos

Uso versionamento como parte da organização do desenvolvimento, separando código estável, funcionalidades e correções conforme o tamanho do projeto.

| Branch | Uso |
| --- | --- |
| `main` | Versão estável, publicável ou principal do projeto. |
| `develop` | Desenvolvimento ativo quando o projeto precisa de uma etapa intermediária antes da versão estável. |
| `feature/nome-da-funcionalidade` | Implementação isolada de novas funcionalidades. |
| `fix/nome-do-ajuste` | Correções pontuais de bug, comportamento ou interface. |
| `release/x.y.z` | Preparação de versão quando o projeto exige fechamento de escopo, testes e publicação. |

Também procuro organizar projetos com componentes reutilizáveis, separação entre telas e serviços, documentação mínima para execução local, checklist de build/deploy e atenção a responsividade.
